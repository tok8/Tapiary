# Tapiary

**タップで簡単、行動記録。**

---
> *Life is a tapestry woven by the taps we make.*
---

Tapiaryは、「いま何したっけ？」「次これやろう」をカード形式でパパっと記録できるアプリです。

## こんなことができます
- **「いま」を1タップで**: 「＋」ボタンを1タップして、現在時刻のカードを追加。今何をしたか書き込めます。
- **カスタムボタンで、ルーティンも簡単に**: よく使う項目（「お薬」「就寝」「家を出発」など）をカスタムボタンとして登録できます。
- **後からでも、間からでも**: 「あ、さっきの記録忘れてた」という時も大丈夫。カードとカードの間にある「＋」から、いつでもどこでも新しい記録を差し込めます。
- **その日だけに集中**: 日付ごとに表示が切り替わるので、タイムラインがごちゃごちゃしません。◀︎▶︎ボタンやカレンダーで、過去の記録もすぐに見返せます。
- **こだわりのデザイン**: 目に優しいマットな色使いと、動かしていて気持ちいいアニメーション。使うのがちょっと楽しくなる、そんな手触りを目指しました。
- **プライバシーも安心**: 記録したデータは、あなたのブラウザの中だけに保存されます。勝手にどこかに送信されることはありません。
    - データが失われた場合、こちらでは復元できません。大切な記録はエクスポートし、バックアップをお願いします。
- **PWA対応**: iPhoneやAndroidの「ホーム画面に追加」をすれば、普通のアプリと同じ感覚で使えます。オフラインでも利用可能です。
