Feat: Phase 2 Sorting & Data Integrity

Implemented robust sorting and data precision improvements:

- **Sorting**: Implemented "Anchor & Dependent" sorting logic. Logs without time now explicitly link to the log above them (`parentId`) and move with it during sorts.
- **Data Precision**: Added `createdAt` timestamp to `LogEntry` to ensure stable sorting for logs added within the same minute.
- **Migration**: Added auto-migration to upgrade existing logs with `createdAt` and `parentId` on load.
- **UI/UX**: 
  - Forced time display and input to use `HH:mm` format to simplify editing.
  - Retained full precision in background for sorting stability.
